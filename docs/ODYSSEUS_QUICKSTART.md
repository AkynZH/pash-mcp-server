# Odysseus Quickstart (Native Windows)

Пошаговое руководство по нативной установке и подключению Odysseus к `pash-mcp-server` на Windows **без использования Docker**.

## Шаг 1: Нативная установка через PowerShell

1. Откройте **PowerShell** (можно без прав администратора, если Python установлен для текущего пользователя).
2. Перейдите в директорию проекта:
   ```powershell
   cd pash-mcp-server
   ```
3. Запустите скрипт инициализации:
   ```powershell
   .\launch-windows.ps1
   ```
   *Этот скрипт автоматически создаст виртуальное окружение (`venv`), активирует его и установит все необходимые зависимости из `pyproject.toml`.*

## Шаг 2: Добавление pash-mcp-server в MCP-конфиг Odysseus

Чтобы Odysseus (или любой другой MCP-клиент, например, Cursor или Claude Desktop) мог взаимодействовать с сервером, добавьте следующую конфигурацию в ваш файл настроек MCP (например, `mcp_config.json`):

```json
{
  "mcpServers": {
    "pash-mcp-server": {
      "command": "python",
      "args": ["server.py"],
      "env": {
        "PYTHONPATH": "."
      }
    }
  }
}
```
> **Важно:** Убедитесь, что пути соответствуют реальной структуре ваших директорий. Сервер работает в режиме `stdio`, поэтому клиент должен запускать его как дочерний процесс.

## Шаг 3: Проверка связи (Тестовый вызов)

Для автоматической проверки того, что Odysseus может успешно вызвать `pash-mcp-server` и получить PASH-сжатый ответ, выполните встроенный тестовый скрипт:

```powershell
.\venv\Scripts\python.exe scripts\test_odysseus_connection.py
```

### Ожидаемый результат:
Скрипт должен вывести:
1. ✅ Успешную инициализацию сервера (MCP `initialize`).
2. ✅ Список доступных инструментов.
3. ✅ Подтверждение того, что при вызове инструментов сервер возвращает структуру с полем `pash_data` (результат работы `AdaptivePashCompressor`).

---
*Примечание: Данная инструкция предназначена исключительно для нативной среды Windows. Docker не требуется и не используется.*
